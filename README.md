# にがてノート

「Web開発の学習中でも、自分の作品をわかりやすく見せたい」人向けのポートフォリオ用アプリです。
初心者でも使いやすいように、シンプルで親しみやすいタスク管理体験を目指しました。

## このアプリで伝えたいこと

- タスクと予定を整理する基本機能を1つのアプリで実装しています
- 初心者でも読みやすい構成で、Next.js と TypeScript を使った開発が学べます
- モバイルにも対応したレスポンシブ UI を作りました
- ブラウザの localStorage でデータを保存します

## 主な機能

- ✅ 今日のタスク管理
- ✅ カレンダー表示
- ✅ タイムブロックで時間を視覚化
- ✅ 優先順位に応じたタスク整理
- ✅ アイゼンハワー4象限でタスクを分類
- ✅ ポモドーロ風の時間記録
- ✅ 「やらないことリスト」で気持ちを整理
- ✅ 達成状況をグラフで確認

## 対象ユーザー

- Web開発を学習している人
- 初めてポートフォリオを作る人
- 自分の制作物を見せたい人
- タスク管理アプリのアイデアを紹介したい人

## 使い方

1. `npm install` を実行
2. `npm run dev` で開発サーバーを起動
3. ブラウザで `http://localhost:3000` を開く

## 技術スタック

- Next.js 16（App Router）
- TypeScript
- Zustand + localStorage
- CSS カスタムプロパティ
- Vercel デプロイ対応

## ポートフォリオの見どころ

- **コンポーネント構成**: 画面を分けて作る設計
- **状態管理**: タスク・ブロックの状態を整理
- **レスポンシブ対応**: スマホでも使えるUI
- **日本語UI**: 使いやすい日本語表示
