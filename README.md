# にがてノート

やることが苦手でも大丈夫。苦手な人向けのやさしいタスク・スケジュール管理アプリです。

🔗 **本番 URL**: https://my-app-mu-eight-87.vercel.app

---

## 機能一覧

| 画面 | 内容 |
|---|---|
| 📋 今日のタスク | 優先度・期限・繰り返し・サブステップ・スコア順並び替え |
| 📅 カレンダー | 月表示でタスクの期限を確認 |
| 🕐 タイムブロック | 時間グリッドにタスクをブロック配置 |
| 🏅 優先順位 | 重要度・緊急度スコアで Big3 を自動抽出 |
| 🎯 アイゼンハワー | 4 象限マトリクスで仕分け |
| ⏱ タイムトラッキング | ポモドーロ形式で集中時間を記録 |
| 🚫 やらないことリスト | 注意が散らないよう「やらないこと」を宣言 |
| 📊 達成グラフ | 曜日別・優先度別の完了数を可視化 |

## サイドバー補助機能

- **今日の気分** — 5段階の絵文字で気分を記録
- **集中力レベル** — スライダーで現在のコンディションを把握
- **フォーカスモード / とりあえず5分** — 着手のハードルを下げるクイックスタート

## 開発

```bash
npm install
npm run dev   # http://localhost:3000
```

> **注意**: ローカルビルド (`npm run build`) は Node.js v20 LTS 推奨。
> v25 系では SWC バイナリの非互換により失敗することがあります。
> Vercel 上では正常にビルドされます。

---

## セキュリティ (スコア 87/100)

- データはブラウザの `localStorage` のみに保存（外部送信なし）
- `dangerouslySetInnerHTML` / `eval` 不使用（XSS リスクなし）
- 既知の CVE: PostCSS < 8.5.10 (CVSS 6.1, moderate) — Next.js 内部 bundle のみ。ユーザー入力 CSS を処理しないため実効リスクは低
