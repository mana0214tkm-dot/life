# 人生ときめき

毎日の予定とタスクをやさしく整理して、小さな達成をときめきに変えるスケジュール管理アプリです。

タスクを完了すると絵文字の育成ロボが段階的に成長し、動きや「すごい！」の吹き出しで達成感を伝えてくれます。タスクや予定などのデータはブラウザの `localStorage` に保存されるため、アカウント登録なしで使い始められます。

## 主な機能

- タスクの追加、完了、削除、期限切れ表示
- 優先度・期限・開始時刻・締め切り時刻・所要時間・繰り返し・メモの設定
- タスクの分解とステップごとの完了管理
- 今日のゆるゴール（完了数の目標）とスコア上位3件の「ビッグ3」
- 未完了・完了・期限・繰り返し・スコア順などのタスク絞り込み
- フォーカスモード（優先度の高い未完了タスクのカウントダウンと完了操作）
- カレンダーでの月移動、期限タスクの確認、完了操作
- タイムブロックの追加、色分け、15分バッファ、削除
- アイゼンハワー・マトリクスの4象限表示と完了操作
- 自動スコアランキングと、タスク同士を比べる「A vs B 比較」
- タスクに紐づけた経過時間の計測と、最大50件のトラッキング履歴
- 経過時間と25分単位の集中ブロックを表示するタイマー
- 達成率、優先度別件数、連続達成日、直近14日、報酬、振り返り表
- タスク達成数に応じて絵文字が変わり、達成時に動く育成ロボ
- サイドバーでの今日の気分と集中力レベルの入力
- モバイル向けレスポンシブレイアウト

## 開発環境

- Next.js 16（App Router）
- React 19
- TypeScript
- Zustand + `localStorage`
- CSS カスタムプロパティ
- Netlify（Next.jsランタイムプラグイン）

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 利用可能なコマンド

```bash
npm run dev      # 開発サーバーを起動
npm run lint     # ESLintを実行
npm run build    # 本番ビルドを作成
npm run start    # 本番ビルドを起動
```

## デプロイ

Netlifyでこのリポジトリを接続すると、`netlify.toml` の設定により `npm run build` が実行されます。
